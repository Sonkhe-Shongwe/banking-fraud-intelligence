# Methodology (planning)

## Core question
How can a financial institution prioritise suspicious transactions while balancing fraud detection, false positives, financial exposure and investigation capacity?

## Research design
Pending dataset audit. Define observation grain, exclusions, validation strategy, denominators, uncertainty and limitations before analysis.

## Quality safeguards
- Prevent leakage and inappropriate causal claims.
- Document missingness and data transformations.
- Validate key measures independently.
- Distinguish observations from assumptions and simulations.
